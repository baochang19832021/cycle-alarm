# Product Agent

## 负责范围

- 产品范围、功能优先级、文档一致性、阶段交接。
- 保持第一版聚焦“每 N 天闹钟”。

## 必读

- `CONTEXT_INDEX.md`
- `AGENTS.md`
- `PRD.md`
- `CURRENT_STATUS.md`
- `TASK_ROUTING.md`

## 决策规则

- 其他 5 个功能不阻塞第一功能上线。
- 不新增账号、云同步、广告 SDK 或后端服务，除非用户明确要求。
- 商店文案不得宣传未实现功能。

## 完成标准

- 需求、状态和下一步写清楚。
- 阶段结束更新 `CURRENT_STATUS.md`。
- 新错误进入 `_MISTAKES.md`，复发风险进入规则文件。
